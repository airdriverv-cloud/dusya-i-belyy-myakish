# Дуся и Белый Мякиш

Сайт-книга по сказке «Дуся и Белый Мякиш. Большое путешествие маленьких друзей».

- Автор — Света Грызлова
- Редактор — Виктор Павлович
- Текст — редакция V09 от 5 ноября 2026
- Иллюстрации — из иллюстрированного издания книги

## Что внутри

| Раздел | Содержание |
| --- | --- |
| Обложка | обложка книги, название, авторы, кнопка «Начать читать» |
| Семь глав | полный текст сказки; 32 иллюстрации стоят по тексту так же, как в книге — по одной между абзацами |
| «Вспомним путешествие» | три вопроса после книги и творческое задание |
| «Благодарности» | финальная страница |

## Удобство чтения

- **Выбор фона: белый или чёрный.** Переключатель в верхней панели (и в содержании).
  Выбор запоминается в браузере; при первом заходе учитывается системная тема.
- **Размер текста** — кнопки «А−» и «А+» (четыре ступени).
- **Содержание** — панель со всеми главами и переходами.
- **Полоса прогресса** чтения и переходы «предыдущая / следующая глава».
- **Иллюстрации** открываются на весь экран по нажатию.
- Плавная адаптация под телефон, планшет и печать.

## Структура

```
index.html            разметка страницы
assets/style.css      оформление и темы (белая / чёрная)
assets/app.js         сборка книги, темы, содержание, просмотр иллюстраций
assets/book-data.js   текст книги и порядок иллюстраций
book-data.json        та же книга в JSON (для сторонних инструментов)
images/               32 иллюстрации в WebP
```

Текст и иллюстрации лежат отдельно от кода: содержимое страницы
собирается из `book-data.js` при загрузке.

## Как открыть локально

```bash
python -m http.server 8000
# затем http://localhost:8000
```

Можно и просто открыть `index.html` — сторонние библиотеки не используются.

## Служебное

Адрес для проверки темы вручную: `?theme=dark` или `?theme=light`
(разовый выбор, в настройках не сохраняется).
